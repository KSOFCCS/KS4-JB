# KS4-JB

**Um WebKit Host independente para PlayStation 4 com integração ao GoldHEN.**
O KS4-JB é um host baseado na web, desenvolvido para PlayStation 4, com uma interface simples, compatibilidade com diferentes versões de firmware e recursos armazenados em cache para acessos posteriores.

## Recursos

- WebKit Host independente para PlayStation 4.
- Integração com GoldHEN.
- Suporte a diferentes versões de firmware.
- Suporte a cache offline.
- Interface simples e leve.
- Opções alternativas de hospedagem.

## Como Usar

1. Abra um dos hosts disponíveis no navegador de Internet do PlayStation 4.
2. No primeiro acesso, aguarde a preparação e instalação do cache.
3. Quando a interface informar que o cache está pronto, pressione **X** para continuar.
4. Siga as instruções exibidas pelo host.

## Cache
O KS4-JB possui um sistema de cache desenvolvido para armazenar localmente os recursos necessários no console.
Após a configuração inicial, os próximos acessos poderão utilizar os arquivos armazenados, reduzindo a necessidade de baixar novamente os mesmos recursos.
O botão **Cache** permite acessar diretamente a página de gerenciamento do cache.
